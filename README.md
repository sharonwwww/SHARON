# 📚 课程学习体会

通过本课程的学习，我对人工智能机器人领域有了更加全面和深入的认识。课程从最基础的Linux环境配置开始，逐步介绍ROS2机器人开发框架、Python编程语言、Docker容器技术以及OpenCV计算机视觉等核心知识，使我能够从零基础逐渐掌握机器人开发的基本流程。

在学习过程中，我完成了Ubuntu与WSL环境搭建，掌握了Linux常用命令和文件管理方法，并学会使用Git和GitHub进行版本控制和项目管理。同时，我学习了ROS2节点、话题（Topic）、服务（Service）等通信机制，能够编写简单的机器人控制程序，实现机器人运动控制与信息交互。

通过机器人运动学和传感器实验，我理解了机器人坐标系、里程计以及传感器数据处理的基本原理。在OpenCV视觉实验中，我学习了图像处理、目标识别以及ArUco二维码识别技术，并能够利用摄像头进行距离测量和视觉定位。

此外，Docker相关实验让我了解了容器化技术在机器人开发中的应用，提高了环境部署和软件管理效率。通过GitHub作业整理和课程项目实践，我进一步提升了自主学习能力、问题分析能力以及团队协作能力。

本课程不仅帮助我掌握了机器人开发的基础知识，也让我对人工智能与机器人融合应用产生了浓厚兴趣，为未来进一步学习SLAM、自动驾驶、强化学习和智能机器人系统奠定了良好的基础。
